# Créditos

Este proyecto está basado en el código original desarrollado por **smoochiee** en el repositorio:

**Bluetooth-jammer-esp32**  
https://github.com/smoochiee/Bluetooth-jammer-esp32

El código base utilizado para el control del ESP32 y los módulos NRF24L01 proviene de dicho proyecto.

## Modificaciones de esta versión

Nuestro equipo realizó modificaciones y documentación adicional, entre ellas:

- Integración de una pantalla OLED SSD1306 de 128x64 píxeles.
- Visualización del modo seleccionado en la pantalla OLED.
- Visualización de los canales de los módulos NRF24L01.
- Adaptación de la comunicación I2C utilizando GPIO 26 y GPIO 27.
- Documentación de conexiones y componentes.
- Elaboración del diagrama de conexión del proyecto.
- Organización del código y documentación dentro de este repositorio.

## Equipo

Los integrantes y contribuciones específicas del equipo se agregarán conforme avance el desarrollo del proyecto.
